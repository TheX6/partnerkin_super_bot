📋 Таск-менеджер

Полноценная система управления задачами

🎯 Создание задач

Кто может: Любой старичок (не стажер)

Для кого: Любой зарегистрированный пользователь

Как создать задачу:
  1. Зайти в раздел "📋 Работа" → "Создать задачу"
  2. Ввести название задачи (например: "Подготовить отчет по продажам")
  3. Описать детали задачи (что именно нужно сделать)
  4. Выбрать приоритет: низкий / средний / высокий
  5. Указать срок выполнения (дата или "завтра", "через неделю")
  6. Выбрать исполнителя из списка пользователей
  7. Указать награду в П-коинах (опционально)
  8. Подтвердить создание

💡 Что происходит после создания:

  • Исполнитель получает уведомление о новой задаче
  • Задача появляется в разделе "Мои задачи"
  • Каждое утро в 9:00 - напоминание о невыполненных задачах

✅ Выполнение задач

Жизненный цикл задачи:
  1. Получение уведомления: "У вас новая задача от @username"
  2. Просмотр: Зайти в "Мои задачи" → увидеть детали
  3. Принятие решения:
    • ✅ Принять - задача переходит в статус "В работе"
    • ❌ Отклонить - нужно указать причину
    • ⏸️ Отложить - предложить новый срок
  4. Работа над задачей: В любой момент можно добавить комментарий
  5. Завершение: Нажать "Отметить выполненной"
  6. Награда: Автоматическое начисление П-коинов (если указаны)

🎁 Преимущества системы задач:

  • Ничего не забудется: Утренние напоминания о всех активных задачах
  • Прозрачность: Создатель видит статус задачи в реальном времени
  • Коммуникация: Комментарии вместо длинных переписок
  • Мотивация: П-коины за выполнение задач
  • Контроль: История всех задач, фильтры, поиск

💬 Комментарии к задачам

Каждая задача - это мини-чат для обсуждения деталей:

  • Задавать уточняющие вопросы
  • Делиться прогрессом
  • Сообщать о проблемах
  • Прикреплять результаты

Уведомления: Все участники получают уведомление о новом комментарии

🏖️ Управление отпусками

Прозрачная система заявок и учета отпускных дней

📝 Подача заявки на отпуск

Как подать заявку:
  1. Зайти в "💼 Работа" → "🏖️ Отпуска"
  2. Нажать "Подать заявку"
  3. Выбрать тип отпуска: оплачиваемый / за свой счет
  4. Указать даты: с какого числа по какое
  5. Написать причину/комментарий (опционально)
  6. Система автоматически рассчитает количество дней
  7. Отправить заявку

📊 Что видит сотрудник:

  • Мой баланс: Сколько дней отпуска доступно в этом году
  • Использовано: Сколько дней уже взято
  • Ожидает одобрения: Дни из заявок на рассмотрении
  • Остаток: Сколько еще можно взять

✅ Преимущества системы:

  • Не нужно писать заявления от руки
  • Автоматический расчет дней
  • Мгновенное уведомление о решении
  • Прозрачный учет баланса
  • История всех отпусков

📚 Модуль "ОБУЧЕНИЕ И РАЗВИТИЕ"

Структурированная система развития навыков для всех уровней

🎓 Два трека обучения

Система обучения адаптируется под роль пользователя: для стажеров - обязательный онбординг, для опытных сотрудников - повышение квалификации.

👶 Трек для стажеров

3 обязательных теста для адаптации

Тест Что изучается Баллы на курсе П-коины в боте
1. Онбординг в Партнеркин История компании, ценности, структура, процессы До 100 0 (не начисляются)
2. Основы эффективной коммуникации Корпоративный стиль общения, каналы связи, этикет До 100 0 (не начисляются)
3. Эффективная работа в режиме многозадачности Тайм-менеджмент, приоритизация, инструменты До 100 0 (не начисляются)
ИТОГО после завершения всех 3 тестов: 400 П-коинов 🎉

📖 Как проходить тесты стажеру:

  1. Зайти в "📚 Обучение и развитие" → "🎓 Курсы"
  2. Выбрать один из 3 доступных тестов
  3. Перейти по ссылке на курс (откроется внешняя платформа)
  4. Пройти курс полностью до конца
  5. На финальной странице увидеть результат (баллы до 100)
  6. Сделать скриншот страницы с результатом
  7. Вернуться в бот → "Пройти тестирование"
  8. Выбрать тест, который прошли
  9. Отправить скриншот
  10. Указать количество баллов (от 0 до 100)
  11. Дождаться проверки администратора

⚠️ Важно для стажеров!

  • За прохождение тестов П-коины НЕ начисляются
  • Баллы (до 100) получаются только на платформе курсов
  • 400 П-коинов начисляются ОДИН РАЗ после завершения всех 3 тестов
  • После этого нужно будет написать приветствие команде
  • И только потом открывается полный доступ ко всем функциям

📊 Отслеживание прогресса

Зайти в "📊 Мой прогресс" - увидеть:

  • ✅ Завершенные тесты (зеленая галочка)
  • ⏳ Незавершенные тесты (часики)
  • "Завершено: X/3" - понятно, сколько осталось
  • Заработанные баллы на курсах

👔 Трек для старичков

4 курса повышения квалификации

Курс Что изучается Награда
1. Информационный стиль и редактура текста Написание текстов, редактирование, работа с контентом До 100 П-коинов
2. Тайм-менеджмент Управление временем, планирование, продуктивность До 100 П-коинов
3. Стресс-менеджмент Управление стрессом, эмоции, выгорание До 100 П-коинов

💰 Система начисления П-коинов:

В отличие от стажеров, старички получают П-коины за КАЖДЫЙ курс сразу после одобрения администратором!

  • Прошли курс на 100 баллов → получили 100 П-коинов
  • Прошли курс на 85 баллов → получили 85 П-коинов
  • Можно проходить курсы в любом порядке
  • Можно проходить параллельно несколько курсов

📖 Как проходить курсы старичку:

  1. Зайти в "📚 Обучение и развитие" → "🎓 Курсы"
  2. Выбрать курс из 4 доступных (видны только курсы для старичков)
  3. Пройти курс на внешней платформе
  4. Сделать скриншот результата
  5. Отправить заявку с указанием баллов
  6. Получить П-коины сразу после одобрения!

🎯 Зачем нужны два трека?

  • Для стажеров: Фокус на адаптации, понимании компании. П-коины - это награда за завершение всего пути, не промежуточный результат
  • Для старичков: Мотивация на постоянное развитие через немедленную награду за каждое достижение
  • Для компании: Понятная система: новички сначала учатся, опытные - развиваются и получают бонусы

⚔️ PVP Сражения

Соревновательная механика для азарта и взаимодействия

🎯 Как работают PVP сражения

📊 Механика:

  • Стоимость боя: 10 П-коинов + 20 энергии
  • Максимум энергии: 100 (хватает на 5 боев подряд)
  • Исход: 50/50 случайный
  • Награда победителю: 20 П-коинов (своя ставка + ставка противника)
  • Проигравший: Теряет 10 П-коинов
Как сразиться:
  1. Зайти в "🎮 Развлечения" → "⚔️ PVP Сражения"
  2. Выбрать "Найти соперника"
  3. Увидеть список всех пользователей с балансами
  4. Выбрать соперника
  5. Подтвердить бой (списывается 10 П-коинов и 20 энергии)
  6. Получить результат: победа или поражение
  7. Оба участника получают уведомления о результате

🎁 Зачем нужны PVP сражения:

  • Азарт и адреналин: Шанс удвоить ставку или потерять её
  • Социальное взаимодействие: Повод пообщаться с коллегами
  • Мотивация зарабатывать: Чтобы было на что сражаться
  • Рейтинг: Можно стать топ-1 по победам
  • Развлечение: Отдых от рабочих задач

⚠️ Защита от эксплуатации:

  • Нельзя сражаться с самим собой
  • Ограничение по энергии (восстанавливается со временем)
  • Проверка баланса (нельзя играть без П-коинов)
  • История всех сражений для прозрачности

💚 Зачем дарить П-коины:
