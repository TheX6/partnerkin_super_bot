Интерактивный Telegram бот для геймификации рабочих процессов в компании.

- **Редактирование слотов** - изменение всех параметров

## 🚀 Установка и запуск

### 1. Подготовка

```bash
# Клонируйте проект
cd partnerkino-bot

# Установите зависимости
npm install
```

### 2. Настройка Telegram бота

1. Найдите бота [@BotFather](https://t.me/BotFather) в Telegram
2. Создайте нового бота командой `/newbot`
3. Выберите имя и username для бота
4. Получите токен доступа

### 3. Настройка PostgreSQL

**Шаг 1: Установите PostgreSQL**
- **Ubuntu/Debian:** `sudo apt update && sudo apt install postgresql postgresql-contrib`
- **Windows:** Скачайте с [официального сайта](https://www.postgresql.org/download/windows/)
- **macOS:** `brew install postgresql`

**Шаг 2: Создайте базу данных**
```bash
# Войдите в PostgreSQL (обычно под пользователем postgres)
sudo -u postgres psql

# Создайте базу данных и пользователя (внутри psql)
CREATE DATABASE partnerkino;
CREATE USER partnerkino_user WITH PASSWORD 'your_secure_password';
GRANT ALL PRIVILEGES ON DATABASE partnerkino TO partnerkino_user;
\q
```

**Шаг 3: Создайте таблицы**
```bash
# Запустите скрипт миграции для создания таблиц в PostgreSQL
node migrate_to_postgres.js
```

### 4. Конфигурация

```bash
# Скопируйте файл примера
cp .env.example .env

# Отредактируйте .env файл
nano .env
```

Настройте переменные окружения в `.env`:
```
# Токен Telegram бота (обязательно)
TELEGRAM_TOKEN=ваш_токен_от_botfather

# Подключение к PostgreSQL (обязательно для работы с PostgreSQL)
DB_TYPE=postgresql
DB_HOST=localhost
DB_PORT=5432
DB_NAME=partnerkino
DB_USER=partnerkino_user
DB_PASSWORD=your_secure_password

# Опциональные настройки
ADMIN_PASSWORD=your_secure_admin_password
PORT=3000
NODE_ENV=production
```

> **ВАЖНО:** Убедитесь, что `DB_TYPE` установлено в `postgresql`.

### 5. Запуск

```bash
# Запуск бота с PostgreSQL
node app.js
```

Бот будет запущен и готов к работе! 🎉

## 🔧 Миграция данных из SQLite в PostgreSQL

Если вы переходите с SQLite и хотите перенести данные:

1. **Создайте таблицы в PostgreSQL** (как показано выше)
2. **Запустите миграцию данных:**
```bash
node migrate_data.js
```
> **ПРЕДУПРЕЖДЕНИЕ:** Этот скрипт перенесет все данные из SQLite в PostgreSQL. Убедитесь, что обе базы данных доступны.

## 🔧 Настройка

### Изменение настроек

Отредактируйте файл `config.js`:

```javascript
// Игровые настройки
GAME: {
    pvp_energy_cost: 20,      // Трата энергии за PVP
    pvp_coins_stake: 10,      // Ставка в PVP
    max_gift_per_day: 50,     // Лимит подарков в день
    min_gift_amount: 5        // Минимальная сумма подарка
}
```

### Администраторы

Пароль для входа в админку задаётся через переменную `ADMIN_PASSWORD` в `.env`.

Для смены пароля измените в `.env`:
```
ADMIN_PASSWORD=новый_пароль
```

## 📊 База данных

### Поддерживаемые системы:
- **PostgreSQL** (рекомендуется для продакшена)
- **SQLite** (только для разработки/тестирования)

### Переключение между базами данных:
- Установите `DB_TYPE=postgresql` в `.env` для использования PostgreSQL
- Установите `DB_TYPE=sqlite` в `.env` для использования SQLite

> **ВАЖНО:** PostgreSQL рекомендуется для продакшена из-за масштабируемости и производительности.

### Таблицы (PostgreSQL):
- `users` - Пользователи
- `clicker_stats` - Статистика тапалки  
- `tasks` - Система задач
- `gifts` - Подарки П-коинов
- `battles` - PVP сражения
- `event_slots` - Мероприятия
- `event_bookings` - Записи на мероприятия
- `test_submissions` - Заявки на тесты
- `purchases` - Покупки в магазине
- `vacation_requests` - Заявки на отпуск
- `vacation_balances` - Балансы отпусков
- `invoices` - Инвойсы продажников
- `company_contacts` - Контакты компаний
- `achievements` - Достижения
- `achievement_likes` - Лайки достижений
- `achievement_comments` - Комментарии к достижениям

## 🆘 Поддержка

При возникновении проблем:

1. Проверьте правильность токена в `.env`
2. Убедитесь что все зависимости установлены (`npm install`)
3. Проверьте доступность PostgreSQL и правильность настроек подключения
4. Убедитесь что `DB_TYPE=postgresql` в файле `.env`
5. Проверьте логи в консоли при запуске
6. Убедитесь что бот добавлен в чат

> **На Windows:** Убедитесь, что служба PostgreSQL запущена и правильно настроена для подключений.
