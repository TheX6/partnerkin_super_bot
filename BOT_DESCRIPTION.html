📋 Общая информация

Назначение

VPartnerkin - это комплексный Telegram-бот для геймификации корпоративных процессов компании Партнеркино. Бот объединяет функции обучения, управления задачами, социального взаимодействия и мотивации сотрудников через игровые механики.

Целевая аудитория

🎓 Стажеры

Новые сотрудники на этапе адаптации. Проходят 3 обязательных теста для получения статуса полноценного сотрудника.

👔 Сотрудники

Полноценные члены команды с доступом ко всему функционалу: PVP, магазин, мероприятия, задачи.

👨‍💼 Администраторы

HR и руководители с расширенными правами: проверка тестов, управление пользователями, статистика.

🎮 Функциональные возможности

1. Система онбординга стажеров

Регистрация

При первом входе /start пользователь проходит через процесс регистрации:

  1. Выбор роли: Стажер или Старичок
  2. Указание ФИО
  3. Указание должности (текущей или желаемой)
  4. Для старичков - выбор уровня (Middle/Senior/Head/C-Level)
  5. Для стажеров - написание краткого био

⚠️ Важно: Система начисления П-коинов для стажеров

Стажеры НЕ получают П-коины за прохождение тестов!

  • ❌ 0 П-коинов за каждый из 3 тестов
  • ✅ 400 П-коинов ОДИН РАЗ после завершения всех 3 тестов
  • 📊 Баллы (до 100) получаются только на платформе курсов

2. Игровая экономика (П-коины)

💰 Способы заработка

  • Прохождение курсов (до 100)
  • Участие в мероприятиях
  • Выполнение задач
  • Победы в PVP
  • Подарки от коллег

💸 Магазин наград

  • Выходной день - 1500
  • Мерч компании - 800
  • Кофе с руководителем - 500
  • Сюрприз от HR - 300

4. PVP Сражения

Механика:

  1. Выбор соперника из списка
  2. Ставка: 10 П-коинов и 20 энергии
  3. Случайный исход (50/50)
  4. Победитель забирает ставку противника

Защита:

  • Ограничение по энергии (max 5 боев подряд)
  • Невозможность играть с самим собой
  • Проверка баланса перед боем

5. Таск-трекер

Статусы:

🆕 Новая

Для кого: Все пользователи
